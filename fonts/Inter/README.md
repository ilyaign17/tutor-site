# Inter — local webfonts

Source: @fontsource-variable/inter 5.2.8, fetched from
https://cdn.jsdelivr.net/npm/@fontsource-variable/inter@5.2.8/

Upstream: https://github.com/google/fonts/tree/main/ofl/inter
Font version: 4.001; git-66647c0bb (Inter 4.1 Google Fonts source).
License: SIL Open Font License 1.1, full notice in OFL.txt.

The original WOFF2 files are unchanged. Seven Unicode subsets preserve the
available character coverage. The CSS exposes the used normal weights 300–800;
no synthetic replacement or glyph editing was performed. Files are served by
GitHub Pages directly. No package or runtime dependency was added.

During validation the live Google stylesheet was unavailable. The before
screenshots use the saved original HTML with offline delivery of the same Inter
version via the Google Fonts request routes. This isolates font transport from
layout. Source version and font metrics were checked against the official TTF.
